# Avgångar Sandudden

Avgångstavla för bussarna mellan Sandudden/Träkvista (Ekerö) och Brommaplan.

- **Till Brommaplan:** Sanduddens vägskäl och Träkvista, bara bussar mot Brommaplan.
- **Hem:** från Brommaplan med 309, 311 och 177, plus reservlinjerna 176 (Ekvägen) och 302 (Träkvista idrottsplats). Markeringarna "Hinner gå / Spring / Hinner inte" utgår från att man är vid Åkeshov, ca 5 minuter från bussen.

Data i realtid från SL:s öppna API (SL Transport, via Trafiklab). Ingen nyckel krävs.
Publiceras med GitHub Pages från grenen `main`.
